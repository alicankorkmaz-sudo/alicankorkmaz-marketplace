# OPEN-QUESTIONS.md Format

`OPEN-QUESTIONS.md` keeps the gaps visible: what to verify, what to research, what only the user can answer.

## Structure

```md
# Open questions

## Open
- **Q007** · verify · {Claim or number to check at its primary source} → F0xx
- **Q008** · research · {Question the talk needs answered}
- **Q009** · user · {Something only the user knows: a date, a name of a talk they saw, a permission}

## Closed
- **Q003** · {YYYY-MM-DD} · {How it was resolved} → research/NNNN | D0xx
```

## Rules

- **Three kinds:** verify (a claim exists but is unconfirmed), research (no answer yet), user (only the user can say).
- **Ask user questions one per message,** when the moment fits, not as a list.
- **Close with the resolution,** never by deleting.
- **Anything added from parametric memory** gets a verify entry.
