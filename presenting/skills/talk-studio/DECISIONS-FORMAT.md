# DECISIONS.md Format

`DECISIONS.md` records what was settled in the idea exchange, so a later session doesn't re-litigate it. Newest first.

## Structure

```md
# Decisions

## D012 — {YYYY-MM-DD} — {Short title}
**Decision:** {What was settled.}
**Why:** {The user's reason, in their words where possible; the evidence if any.}
**Affects:** BRIEF | FLOW §{n} | research scope
**Supersedes:** D00x (if any)
```

## Rules

- **Record only settled points.** Open debates go to `OPEN-QUESTIONS.md`.
- **Keep the user's reason.** "Ownership must be the spine because responsibility is what this transformation is really about" is worth more than "spine: ownership".
- **Supersede, don't delete.** A reversed decision gets a new entry pointing to the old one.
- **Typical decisions:** the spine and thesis, format (talk vs conversation vs hands-on), what stays out of the talk, tone, audience scope, stakes level, confidentiality choices.
