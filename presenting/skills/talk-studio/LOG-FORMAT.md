# LOG.md Format

`LOG.md` is the session diary. Newest entry first. It lets a session that starts days later pick up in seconds.

## Structure

```md
# Log

## {YYYY-MM-DD} — {Short title of the session}
- Added: {research notes, facts, sources}
- Decided: {D0xx titles}
- Wrote: {FLOW.md sections, revisions}
- Next: {the most useful next step}
```

## Rules

- **One entry per session,** written at session end.
- **Three to six lines.** Detail lives in the files the entry points to.
- **If the talk lives inside a project with its own log** (a status file), write there too, following that project's convention.
