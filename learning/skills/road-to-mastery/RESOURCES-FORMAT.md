# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Knowledge blocks and expert solutions draw from here, not from parametric guesses. Wisdom comes from the communities listed here. Phase 3 mental models are sourced here too.

## Structure

```md
# {Topic} Resources

## Knowledge
- [Book: _{title}_ by {author}]({url})
  {One line: what it covers. Use for: …}
- [Paper/Article: "{title}" ({venue})]({url})
  {One line. Use for: …}

## Practitioner mental models (for Phase 3)
- [{Source}]({url})
  {Which model or heuristic it documents, and how well-evidenced it is: established | supported | folklore}

## Wisdom (Communities)
- [{Community}]({url})
  {Why it is high-signal. Use for: …}
- Local: {venue}
  Use for: …

## Gaps
- {An area the mission needs where no good resource has been found yet. Drives future search.}
```

## Rules

- **High-trust only.** Primary sources, recognised experts, peer-reviewed work, well-moderated communities. Marketing dressed as education stays out.
- **Annotate every entry.** A bare link is useless in three months.
- **Grade mental models.** Top performers' heuristics range from well-evidenced to folklore. Say which.
- **Surface gaps explicitly.**
- **Prune ruthlessly.** Five sharp sources beat thirty mediocre ones.
- **Record community preferences.** If the user opted out of communities, note it so future sessions don't keep proposing them.
