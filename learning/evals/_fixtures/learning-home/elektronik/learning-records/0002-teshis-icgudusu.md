# Teşhis sezgisi güçlü, güvenlik farkındalığı temkinli

Kettle senaryosunda doğru eleme sırası kurdu (kablo → enerji yolu), "hiç tepki yok = besleme kesik" çıkarımını kendisi yaptı. Cihaz açmayı güvenlik bilgisi olmadığı için reddetti — bu temkinlilik korunmalı, güvenlik modülü (220V, kondansatör deşarjı, çift yalıtım) ilk pratik oturumların önkoşulu.
